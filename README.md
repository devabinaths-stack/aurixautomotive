# AURIX — Engineered to Move

A premium automotive concept website for the AEGON STUDIOZ portfolio.

## Run locally

```bash
npm.cmd install
npm.cmd run dev
```

Open http://localhost:3000

## Deploy

The project is ready for Vercel/Netlify deployment. It uses Next.js 15, React, TypeScript and Framer Motion.

## Notes

- AEGON STUDIOZ appears only as the subtle footer design/development credit.
- Automotive photography is loaded from Unsplash remote URLs for the demo. For a commercial launch, replace these with licensed local WebP/AVIF assets.
- The configurator uses cinematic image-state switching and CSS color treatment rather than requiring a heavy 3D car asset.
- No real pricing or reservation backend is connected; the private-experience form shows a frontend confirmation.
